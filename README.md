# AI Research DCH School — public website

Публичная статическая витрина школы. Исходные рабочие материалы и внутренняя документация остаются в приватном репозитории ai-interpretability-course.

## Structure

- index.html — главная страница
- tracks/ — направления обучения
- lessons/ — опубликованные лекции
- news/ — новости и авторские публикации с датами и иллюстрациями
- admin/ — публичный визуальный прототип будущей панели управления (не защищён и не является рабочей CMS)
- styles/, scripts/, assets/ — стили, скрипты и графика

## GitHub Pages

В репозитории откройте Settings → Pages и выберите GitHub Actions как источник публикации. Workflow .github/workflows/pages.yml размещает содержимое корня репозитория. После успешного запуска сайт будет доступен по адресу https://dach1980.github.io/ai-research-dch-school/.

## Ограничения

GitHub Pages — статический хостинг. Страница admin/ пока является только макетом интерфейса: здесь нет авторизации, базы данных, серверного сохранения, управления пользователями или реального редактирования публикаций. Не размещайте секреты, пароли и персональные данные в этом репозитории.
