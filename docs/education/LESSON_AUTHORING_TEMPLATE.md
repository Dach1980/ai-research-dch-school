# Шаблон авторства уроков DCH School

**Обязательный визуальный эталон:** урок 1.1.1  
**Файл-шаблон:** `templates/lesson-page-template.html`  
**Дизайн:** `styles/lesson-reference-111.css`  
**Общие компоненты:** `styles/lesson-design-system.css`, `styles/lesson-content-components.css`

## Как создавать новый урок

1. Сначала добавьте числовой код, UID, локализованные названия, outcomes, prerequisites и URL в `data/catalog/catalog-v3.json`.
2. Создайте три страницы RU / EN / 中文 на основе `templates/lesson-page-template.html`.
3. Заполните все placeholders в каждой локализации. Не оставляйте `{{PLACEHOLDER}}` в готовой странице.
4. Скопируйте из эталона только оболочку. Лекционный текст, схемы, практические задания, источники, словарь и вопросы должны быть уникальными для темы.
5. Используйте общие CSS и JS. Inline `<style>` запрещён. Inline-стили внутри SVG допускаются только как часть уникальной схемы и должны быть минимальными.
6. Добавьте тесты существования трёх страниц, корректности canonical URL, структуры шаблона, источников, словаря и ключей самопроверки.
7. Установите статус `review`, выполните CI, Pages deployment и ручную проверку desktop/mobile.
8. Только после прохождения quality gate установите `status=published` и `content_state=published`.

## Обязательные placeholders

| Placeholder | Содержимое |
|---|---|
| `{{LOCALE}}` | `ru`, `en` или `zh` |
| `{{PAGE_DESCRIPTION}}` | Локализованное описание страницы для поиска и соцсетей |
| `{{CANONICAL_URL}}` | Канонический абсолютный URL конкретной локали |
| `{{LESSON_CODE}}` | Только числовой код: например `1.2.1` |
| `{{TRACK_CODE}}` | Буква направления отдельно от номера: `A`, `B`, `C` |
| `{{THEME_CODE}}`, `{{MODULE_CODE}}` | Числовые уровни иерархии |
| `{{LESSON_TITLE}}`, `{{LESSON_LEAD}}` | Локализованные заголовок и аннотация |
| `{{LESSON_METADATA}}` | Три span-метаданных в едином визуальном стиле |
| `{{PLANET_LABEL}}`, `{{PLANET_DESCRIPTION}}` | Подпись и описание планетного баннера |
| `{{LEARNING_OUTCOMES}}` | Список наблюдаемых результатов обучения |
| `{{LECTURE_CONTENT}}` | Основной лекционный материал, разделы, схемы, примеры и практика |
| `{{SOURCES}}` | Список проверяемых первичных и авторитетных источников |
| `{{LESSON_NAVIGATION}}` | Кнопки карты, следующего опубликованного урока, программы трека и всех уроков |
| `{{GLOSSARY_CARDS}}` | Локализованные карточки ключевых терминов |
| `{{SELF_CHECK_QUESTIONS}}` | Вопросы с корректными ключами и объяснениями |
| `{{SITE_NAVIGATION}}`, `{{FOOTER_TAGLINE}}` | Локализованные общий header и footer |

## Числовая нумерация разделов

- Разделы лекции нумеруются последовательно: `1.`, `2.`, `3.` и т.д.
- Подразделы наследуют номер родительского раздела: `3.1.`, `3.2.`.
- После лекционного материала следуют практика, источники, нижняя навигация, словарь и самопроверка.
- Не допускаются пропуски, дубли и обратный порядок номеров.
- Не используйте `A.1`, `A.1.1`, `A.1.1.1` как публичные номера уроков. Track A/B/C указывается отдельно.

## Правило точного соответствия

Структурные блоки должны сохранять классы и порядок из `templates/lesson-page-template.html` и эталонных страниц 1.1.1. Каждая локализация оформляется точь-в-точь по этому эталону:
`site-header → track-hero article-hero → lesson-planet-banner → article-body → lesson-sources → lesson-nav → lesson-glossary → lesson-check → footer`.

Если для новой темы нужен компонент, которого нет в общей системе, сначала добавьте его в общий stylesheet/компоненты и тесты. Не создавайте новый вариант оболочки страницы.
