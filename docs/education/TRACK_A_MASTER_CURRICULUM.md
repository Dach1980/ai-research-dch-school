# Track A — утверждённая мастер-архитектура

**Дата утверждения:** 2026-11-16  
**Статус:** утверждено пользователем целиком  
**Версия:** 2.0

Этот документ — источник истины для детализированной программы Track A (Themes 1–5). Макроархитектура DCH 00–39 остаётся отдельным уровнем; соответствие между уровнями фиксируется в crosswalk. Утверждение архитектуры не означает готовность уроков к публикации и не разрешает изменения каталога или навигации.

## 1. Цель и последовательность

Track A — Understanding AI / XAI Practitioner. Обязательный маршрут: **Theme 1 → Theme 2 → Theme 3 → Theme 4 → Theme 5**.

- Theme 1: базовое понимание AI/ML, данных, моделей и оценки.
- Theme 2: исследовательские инструменты, Python, математика, статистика и экспериментальная методология.
- Theme 3: устройство и обучение ML/DL-моделей.
- Theme 4: интерпретируемые модели, причинные основы и классические методы XAI.
- Theme 5: анализ нейросетей, LLM и AI-агентов, научная проверка качества объяснений.

Theme 2 обязательна полностью: все 8 модулей и 42 урока. Диагностика не заменяет прохождение модулей.
