# Классические методы объяснения ML-моделей — исследовательский блок

Папка содержит авторскую педагогическую переработку тем стороннего AIS Module 07 для возможного включения в Track A DCH School.

- `PEDAGOGICAL_ANALYSIS.md` — анализ источника, сильные/слабые стороны, методологические уточнения.
- `LESSON_BREAKDOWN.md` — предложение из 24 коротких уроков, prerequisites и зависимости.
- `SOURCE.md` — паспорт источника и ограничения использования.

**Статус:** proposed. Не является утверждённым DCH module_id или окончательным syllabus. Внешний Module 07 не равен модулю 07 DCH.

Точный номер в основной 40-позиционной сетке не назначен до завершения реконструкции Track A.
