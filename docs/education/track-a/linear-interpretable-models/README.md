## Важное замечание об исходном PDF

PDF предоставлен пользователем для анализа и доступен в текущей рабочей сессии. Используемый GitHub-инструментарий позволяет создавать текстовые файлы и Git blobs, но не предоставляет прямой передачи локального бинарного файла из рабочей среды в репозиторий. Поэтому оригинальный PDF в эту папку пока не загружен; здесь сохранены его паспорт, анализ и авторская переработка. Для размещения самого PDF потребуется отдельная загрузка бинарного файла через Git-клиент/веб-интерфейс GitHub либо другой разрешённый бинарный upload workflow. Перед публичным распространением оригинала необходимо проверить лицензию правообладателя.
