# Privacy Policy — draft

**Not approved for publication.** Before collecting personal data, identify the actual data controller and applicable jurisdiction; document the data categories, purposes and legal bases, Supabase project region and subprocessors, international transfers, retention periods, security measures, user rights, account deletion/data export procedures, contact details, effective date, and obtain appropriate legal review.

The current implementation is designed to process account email, optional display name, locale preference, authentication/session metadata, and learning access entitlements. Actual processing must be verified against the final Supabase configuration.
