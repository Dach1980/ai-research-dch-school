**Не создавать фиктивную реконструкцию под именем первичного документа.** До обнаружения исходного ZIP/файла:
- не назначать Module 04 AIS конкретный DCH module_id;
- не утверждать, что дубли между всеми 40 модулями проверены;

- не создавать prerequisite edges на основании одной только последовательности номеров;
- сохранять текущий crosswalk Module 04 как предварительную тематическую рекомендацию.
