## 1. Вывод для программы DCH

Материал AIS Module 04 тематически относится прежде всего к направлению Explainable AI / интерпретируемые модели. По доступной исторической схеме DCH это кандидат на покрытие Track A, диапазон модулей 11–26. Однако это только тематическое соответствие: точный номер модуля DCH и соответствие конкретным названиям 40-модульного плана не установлены.

Нельзя присвоить конкурентному модулю номер DCH «04»: номер 04 у AIS — номер их учебного модуля, а не номер нашего курса. Также нельзя объявить все 50 предложенных микроуроков обязательными.

## 4. Карта математических prerequisites

| Подготовка | Где нужна | Как дать новичку |
|---|---|---|
| Координаты, векторы, евклидово расстояние | KNN, SVM | Короткий вводный урок с рисунками и ручным расчётом |
| Масштабирование и среднее | KNN, метрики | Практика на двух признаках с разными единицами измерения |
| Скалярное произведение, прямая и гиперплоскость | SVM | Сначала геометрия, затем минимальная формула |
| Производная, градиент, оптимизация | Формальная теория SVM, boosting | Интуитивный мини-блок; формальные выводы optional |
| Условная вероятность, Байес, логарифм | Naive Bayes | От таблицы частот к формуле и числовому примеру |
| Gini, энтропия, логарифм | Decision Tree | Начать с неоднородности групп и простых подсчётов |
| Bootstrap, среднее, дисперсия | Random Forest | Симуляция повторных выборок |
| Корреляция, метрики качества, перестановки | Feature importance | Один набор данных и сравнение двух оценок |
| Графы, связность, MST | HDBSCAN | Отдельная необязательная математическая вставка |
| CNN, feature maps, similarity | ProtoPNet | Отдельный prerequisite-блок до ProtoPNet |
| Нейросети, softmax, вероятностные веса | MoE | Обзор gating на простом числовом примере |

**Правило:** базовый маршрут не должен требовать предварительного знания ККТ, матричного исчисления, MST, CNN или тонкостей градиентной оптимизации. Эти темы раскрываются в дополнительных уроках непосредственно перед соответствующими факультативными расширениями.

## 6. Что исключить из обязательного новичкового маршрута

Не исключать из образовательного продукта навсегда, но вынести из обязательной последовательности:

- доказательства KKT и двойственной задачи SVM;
- подробную математику HDBSCAN/MST;
- глубокое сравнение внутренних метрик важности библиотек;
- Linear/Neural Trees как специализированные архитектуры;
- оптимизацию MoE gating;
- архитектурные детали ProtoPNet и CNN;
- ikNN как частный исследовательский вариант.

Причина: они требуют дополнительных математических/архитектурных знаний и не нужны для достижения базовых результатов по пониманию нелинейных моделей и интерпретации прогнозов.
