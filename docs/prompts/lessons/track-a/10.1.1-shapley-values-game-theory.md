## 3. Обязательная последовательность содержания

Построй урок от интуиции к формализации и далее к ML-интерпретации.

### 3.1. Мотивация: как распределить общий результат?

Начни с кооперативной ситуации, в которой несколько участников совместно создают общий результат, например три участника проекта с разным вкладом. Покажи проблему: вклад каждого зависит от того, с кем он объединился и в каком порядке участники присоединились.

Не используй упрощённую формулу «общий результат разделить поровну» как определение справедливости. Объясни, что Shapley Value задаёт конкретное аксиоматическое правило распределения вклада в рамках определённой игры.

### 3.2. Модель кооперативной игры

Введи обозначения:
- N — полное множество игроков;
- n — количество игроков;
- S ⊆ N — коалиция;
- i ∈ N — отдельный игрок;
- v(S) — ценность/выигрыш коалиции S;
- v(∅) — ценность пустой коалиции (объясни принятую нормировку; не объявляй её нулём без оговорки).

Различай:
- участника игры и коалицию;
- ценность коалиции и предельный вклад участника;
- общий выигрыш игры и распределение этого выигрыша между участниками.

### 3.3. Предельный вклад

Определи предельный вклад игрока i в коалицию S, где i не входит в S:

Δᵢ(S) = v(S ∪ {i}) − v(S).

Объясни на одном согласованном примере, почему вклад одного и того же игрока может различаться в разных коалициях. Не называй Δᵢ(S) постоянным «вкладом признака»: это вклад при конкретном контексте коалиции.

### 3.4. Все порядки добавления и средний вклад

Для небольшой игры из трёх игроков перечисли все 3! = 6 возможных порядков добавления. Покажи, какой предельный вклад получает каждый игрок в каждом порядке, а затем усредни значения по всем шести порядкам.

Объясни, почему усреднение по всем порядкам не означает, что в реальном процессе признаки обязательно добавляются последовательно. Это математический способ симметрично учесть все возможные контексты.

### 3.5. Формула Shapley Value

Введи формулу:

φᵢ(v) = Σ_{S ⊆ N \ {i}} [ |S|! (n − |S| − 1)! / n! ] · [v(S ∪ {i}) − v(S)].

Расшифруй каждую часть:
- φᵢ(v) — значение Шепли игрока i;
- S — коалиция без i;
- |S| — размер коалиции;
- n — общее число игроков;
- факториалы — число порядков, в которых заданная коалиция может оказаться перед i, а остальные игроки — после него;
- второй множитель — предельный вклад i в коалицию S;
- сумма — взвешивание всех допустимых коалиций.

Объясни эквивалентность формулы среднего по всем n! перестановкам. Не оставляй комбинаторный вес как «магический коэффициент»: покажи его происхождение на примере n=3 и размеров коалиций 0, 1 и 2.

### 3.6. Четыре аксиомы

Разбери отдельно и с коротким примером:

1. **Эффективность (Efficiency):** сумма значений Шепли равна v(N) − v(∅). Если v(∅)=0, сумма равна v(N). Обязательно различай total value и распределённый прирост.
2. **Симметрия (Symmetry):** если два игрока дают одинаковый предельный вклад во всех коалициях, их значения Шепли равны.
3. **Фиктивный игрок (Dummy / Null player):** если добавление игрока никогда не меняет ценность любой коалиции, его значение Шепли равно нулю.
4. **Аддитивность (Additivity):** значение Шепли для суммы двух игр равно сумме соответствующих значений Шепли в каждой игре.

Покажи, что эти аксиомы совместно характеризуют правило Shapley Value для заданного класса игр. Не заявляй, что аксиомы гарантируют причинную истинность, отсутствие смещения или объективную справедливость в любом прикладном контексте. Кратко обсуди зависимость «справедливости» от определения самой игры и функции ценности.

### 3.7. Перенос на объяснение ML-модели

Сопоставь элементы игры и задачи объяснения:

| Кооперативная игра | Объяснение модели |
|---|---|
| Игрок | Признак |
| Коалиция S | Подмножество признаков |
| v(S) | Определённая функция выхода модели для коалиции |
| Предельный вклад | Изменение ценности при добавлении признака |
| Shapley Value | Усреднённый вклад признака по контекстам |

Обязательно добавь оговорки:
- «отсутствующий» признак не имеет одного универсального смысла;
- функция v(S) требует способа определить выход модели при неполном наборе признаков;
- выбор фонового распределения, условного/маргинального ожидания и способа представления отсутствующих признаков влияет на игру и значения;
- признаки могут быть зависимы, поэтому независимое исключение признаков может порождать нереалистичные комбинации;
- значение Шепли распределяет вклад относительно выбранной функции ценности, но не доказывает причинный эффект признака;
- значение зависит от выхода модели/шкалы, выбранной функции ценности и контекста объяснения.

На этом уровне объясни постановку, но не уходи в детали реализаций KernelSHAP, TreeSHAP, DeepSHAP, sampling, background datasets API и кода библиотеки. Это предмет 10.1.2 и последующих занятий.

### 3.8. Shapley Value и SHAP — не одно и то же

Чётко раздели:
- Shapley Value — математическое правило распределения общего прироста ценности в кооперативной игре;
- SHAP — семейство методов объяснения предсказаний модели, использующее значения Шепли и конкретные способы построения/оценки функции ценности.

Не называй Shapley Value самостоятельной библиотекой или конкретным алгоритмом. Не утверждай, что все реализации SHAP всегда вычисляют точные значения для любой модели и любого числа признаков. Оставь детали вычислительных методов уроку 10.1.2.

### 3.9. Итог и переход

Сформулируй компактную цепочку:
**кооперативная игра → коалиции → предельный вклад → все порядки/взвешивание → Shapley Value → функция ценности модели → основа SHAP**.

Заверши вопросом, который естественно ведёт к 10.1.2: если математическое определение требует оценить значения для множества коалиций, как это сделать практически для реальной модели и большого числа признаков?

## 4. Сквозной числовой пример — обязательный

Используй один полностью согласованный пример игры с тремя игроками A, B и C. Не меняй числа между текстом, формулами, таблицами, диаграммами, практикой и quiz.

Задай значения коалиций:

| Коалиция | v(S) |
|---|---:|
| ∅ | 10 |
| {A} | 14 |
| {B} | 13 |
| {C} | 11 |
| {A,B} | 18 |
| {A,C} | 16 |
| {B,C} | 15 |
| {A,B,C} | 20 |

Обязательные контрольные значения:
- общий прирост игры: v(N) − v(∅) = 20 − 10 = 10;
- φ_A = 14/3 ≈ 4.667;
- φ_B = 11/3 ≈ 3.667;
- φ_C = 5/3 ≈ 1.667;
- сумма: 14/3 + 11/3 + 5/3 = 30/3 = 10.

Покажи расчёт не только итоговых значений, но и промежуточных предельных вкладов. Проверь арифметику программным тестом или независимым ручным расчётом. Если в тексте или визуализации числа не сходятся, исправь пример до создания урока.

Для шести перестановок построй таблицу только после независимого пересчёта предельных вкладов. Не используй предварительные или черновые значения. Проверенные вклады для заданной таблицы коалиций:
- A → B → C: (4, 4, 2);
- A → C → B: (4, 4, 4);
- B → A → C: (5, 3, 2);
- B → C → A: (5, 2, 5);
- C → A → B: (5, 4, 1);
- C → B → A: (5, 4, 1).

Используй именно пересчитанные значения, а не ошибочную промежуточную таблицу. Средние должны дать φ_A=14/3, φ_B=11/3, φ_C=5/3. В таблице порядок столбцов вкладов должен быть явно обозначен; в сумме по каждой перестановке должно получаться 10.
