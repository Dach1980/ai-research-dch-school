## Что не считается завершённым

1. GitHub Pages deployment для последнего commit на момент отчёта ещё выполнялся/ожидал запуска. Не считать production публикацию подтверждённой до успешного завершения workflow.
2. Не проведено визуальное браузерное тестирование desktop/mobile и проверка работающего Pages URL после деплоя.
3. Не проверены Supabase project URL/anon key, SMTP, redirect URLs, email verification, password reset и RLS на реальном проекте.
4. Административная панель не является CMS и не защищена реальной авторизацией.
5. Платный и зарегистрированный контент нельзя хранить в публичных статических HTML/JS/JSON файлах GitHub Pages. Для него требуется защищённое хранилище и серверная проверка доступа.
6. `TERMS_DRAFT.md` и `PRIVACY_POLICY_DRAFT.md` остаются черновиками. Их нельзя объявлять окончательными юридическими документами без проверки реквизитов, обработки персональных данных и юрисдикции.
7. Полные уроки A.3, A.4 и A.5 ещё не созданы.

## Следующий учебный этап

Создавать уроки в последовательности:
1. A.3 — «Как машина учится на данных».
2. A.4 — «Что такое модель машинного обучения».
3. A.5 — «Как проверяют качество модели».

A.3 должен объяснить выборку и наблюдения, признаки и целевую переменную, обучающую процедуру, функцию потерь, оптимизацию, train/validation/test, обобщающую способность, переобучение и недообучение. A.4 должен строго развести модель, алгоритм обучения и AI-систему. A.5 должен охватить baseline, метрики, разбиения, data leakage, пороги решений и оценку на новых данных.
