线性模型作为可解释模型

线性模型通过特征与系数的显式组合给出预测。但公式简短并不自动意味着解释可靠。本课将学习如何读取系数、把预测分解为各特征贡献，并检查这种解释的适用边界。

学习目标

完成本课后，你将能够：

  • 写出线性模型，并说明特征、系数和截距的作用。
  • 在其他特征保持不变且考虑测量单位的条件下解释系数的符号与大小。
  • 将预测分解为参考基准值和各特征贡献。
  • 说明特征缩放与编码如何影响系数解释。
  • 识别多重共线性、系数不稳定、模型设定错误，以及把相关关系误当成因果关系等局限。
本课要解决的问题一个模型只有三个系数，预测公式也只有一行。这是否意味着我们已经理解它为何给出某个数值？只有知道特征和单位的含义、系数如何得到及是否稳定，以及模型适用于什么范围，才能作出这样的判断。

1. 为什么可以直接检查线性模型

上一课区分了模型本身的可解释性与通过额外方法生成的解释。线性模型通常被称为按设计可解释（interpretable by design）：其结构明确呈现特征与预测之间的关系。

它的优势不是神奇的透明性，而是紧凑的表示。我们可以检查哪些特征进入公式、分配了哪些权重，以及特征值如何参与计算。需要区分三个判断：公式容易阅读；系数可以被估计；系数能够为具体任务提供有意义的解释。第一个判断并不能保证后两个判断。

线性模型（linear model）预测值由指定特征与待估参数的线性组合构成的模型。这里的线性是指参数线性；输入特征本身可以经过预先变换。
按设计可解释（interpretable by design）模型结构本身允许直接检查输入、参数与输出之间的关系，而不需要额外的事后解释器。

2. 线性预测由什么构成

对于数值预测，基础模型可以写成截距加上各特征值与其系数乘积的总和。

线性模型ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ预测值等于参考水平加权特征之和

ŷ 是模型预测值，不一定等于观测值；xⱼ 是第 j 个特征值；βⱼ 是该特征的系数；β₀ 是截距；p 是特征数量。

系数（coefficient）当其他特征保持不变时，对应特征每增加一个单位，模型预测值改变的数值参数。
截距（intercept）所有纳入模型的特征均为零时，公式给出的预测值。它是否具有实际含义，取决于该点在具体领域中是否合理。

关键限定是“其他条件不变”（holding other features constant）。β₂描述的是 x₂ 增加一个单位、其他 x 值保持不变时，模型预测值的变化。这是指定模型内部的条件关系，并不意味着现实世界中可以只改变一个因素而让其他因素完全不变。线性意味着所选预测尺度上的固定步长，而不是自然规律必然线性的证明。

3. 用一个例子读取系数

设想一个用于教学的月租金模型，目标变量以千卢布为单位。特征以一套参考公寓为中心化：面积 50 平方米，距离地铁站 1.5 公里。以下系数仅用于教学，并非根据真实市场数据估计。

以参考值为中心化的租金模型ŷ = 55 + 0.45 · (S − 50) − 1.2 · (D − 1.5)预测月租金，单位为千卢布
  • S 表示面积，单位为平方米；
  • D 表示到地铁站的距离，单位为公里；
  • 0.45 表示 D 不变时，面积每增加 1 平方米，预测租金增加 0.45 千卢布；
  • −1.2 表示 S 不变时，距离每增加 1 公里，预测租金减少 1.2 千卢布；
  • 55 表示面积 50 平方米且距地铁 1.5 公里时的预测值。

面积系数为正，表示在地铁距离相同的情况下，面积每增加 1 平方米，预测租金增加 0.45 千卢布，即 450 卢布。距离系数为负，表示在面积相同的情况下，距离每增加 1 公里，预测租金减少 1.2 千卢布。

对于面积 60 平方米、距地铁 0.5 公里的公寓，面积偏差为 +10 平方米，距离偏差为 −1 公里：

逐步计算预测值ŷ = 55 + 0.45 · 10 − 1.2 · (−1) = 60.7每月 60.7 千卢布

面积贡献为 +4.5 千卢布，距离贡献为 +1.2 千卢布，参考基准值为 55 千卢布，总和为 60.7。距离系数为负，但该公寓比参考点更靠近地铁，因此相对于参考点的贡献为正。这个计算展示模型内部的运算，却不能证明扩大面积会因果性地使真实租金增加 450 卢布。

4. 全局结构与局部贡献

系数描述整个模型。某个特征对具体预测的贡献，还取决于该特征相对于所选参考点的取值。本例中，面积的全局系数始终为每平方米 0.45 千卢布。但相对于 50 平方米，面积 51 平方米的贡献是 +0.45 千卢布，60 平方米是 +4.5 千卢布，45 平方米则是 −2.25 千卢布。

中心化模型的局部分解ŷ(x) = β₀ + Σⱼ βⱼ · (xⱼ − xⱼ,ref)参考水平 β₀ 加上各个特征贡献

参考值 xⱼ,ref 可以是均值、中位数或有实际意义的基准。更换参考点会改变基准值与各项贡献的分解；只要公式同步改写，预测值不应改变。不要把 βⱼ 与 βⱼxⱼ 当成同一概念：系数是模型斜率，贡献则是系数乘以特征值或其相对参考值的偏差。

5. 测量单位、缩放与编码

系数依赖测量单位。如果面积从平方米改为以十平方米为单位，系数数值会缩小十倍，但预测值保持不变。因此，不能简单地把绝对值最大的系数所对应的特征称为最重要特征。

连续特征的标准化系数βⱼ* = βⱼ · SD(xⱼ) / SD(y)特征增加一个标准差时，预测值变化的目标标准差数量

SD(xⱼ) 是特征标准差；SD(y) 是目标变量标准差。标准化有助于在共同尺度上比较连续特征的线性效应，但不会形成通用的重要性指标。二元特征从 0 到 1 的变化有不同含义；独热编码类别的系数表示该类别相对于被省略的基准类别的差异；对数或非线性变换也会改变单位解释。始终说明编码方式、单位、参考点和“其他条件不变”的限定。

6. 何时不能把系数当作可靠解释

即使是简单模型，也可能产生不稳定或误导性的系数。问题往往来自数据与模型设定，而不是公式长度。

多重共线性（multicollinearity）一个特征与一个或多个其他特征高度相关的情况，可能导致单个系数估计不稳定。
系数稳定性（coefficient stability）当样本、模型设定或拟合过程发生合理变化时，系数估计仍能保持相近数值的性质。
  • 特征相关。 公寓面积与房间数量通常相关。模型可能仍能较好预测租金，却无法稳定地区分二者各自的贡献。
  • 函数形式错误。 固定系数可能把不同的非线性区间平均在一起。应通过残差和留出数据检查线性假设。
  • 遗漏或测量不准确的特征。 已纳入特征的系数可能反映的不只是表面上描述的关系。
  • 外推。 在数据范围之外，公式仍会延长直线，即使这种延伸在实际领域中没有意义。
  • 统计显著性。 较小的 p 值并不意味着特征具有实质重要性，也不能证明系数稳定或具有因果含义。统计不确定性、预测质量和解释质量是不同问题。

Ridge 和 Lasso 等正则化方法可以降低系数波动或把部分权重压到零，但会改变估计问题并引入偏差。特征相关时，Lasso 的选择可能依赖具体样本。正则化不能自动证明剩余系数就是真实解释。

回归系数不会因为模型透明、公式中包含其他特征，就自动成为因果效应。因果结论需要恰当的因果问题设定、对混杂因素的处理以及额外假设。

7. 实践实验：只改变一个特征

假设其他特征保持不变，特征 xⱼ 改变 Δxⱼ，则模型预测应改变 βⱼ·Δxⱼ。先计算面积 60 平方米、距地铁 0.5 公里的公寓预测值，再只把距离改为 1.0 公里。

Python 3.10+ · 仅使用标准库
def predict(area_m2, distance_km):
    area_effect = 0.45 * (area_m2 - 50)
    distance_effect = -1.2 * (distance_km - 1.5)
    baseline = 55.0
    prediction = baseline + area_effect + distance_effect
    return prediction, baseline, area_effect, distance_effect

for distance in (0.5, 1.0):
    result = predict(area_m2=60, distance_km=distance)
    print(result)

预期输出：(60.7, 55.0, 4.5, 1.2) 和 (60.1, 55.0, 4.5, 0.6)。

距离从 0.5 公里增加到 1.0 公里时，预测值减少 0.6 千卢布，即 −1.2 × 0.5。代码没有训练模型，也不能证明系数质量；它只验证给定公式如何把输入映射为预测。

独立练习。 保持距离不变，把面积从 60 改为 62 平方米。运行前先预测变化：增加 0.9 千卢布。然后验证计算，并解释为什么这不是对真实租赁市场进行的因果实验。

8. 如何判断线性模型是否适合解释

向用户展示系数之前，不仅要确认公式存在，还要检查解释它的条件是否合理。

  • 特征有明确含义。 每个特征都有清楚的定义、单位和可重复的测量规则。
  • 编码透明。 基准类别、变换、缺失值处理、交互项和中心化方式都有记录。
  • 系数稳定。 在样本或设定的合理变化下，系数不会剧烈变化，并报告估计不确定性。
  • 函数形式适当。 残差与留出数据验证没有显示严重非线性或系统性误差。
  • 适用范围明确。 对象处于数据适用范围内；局限与禁止作出的因果结论均已说明。
  • 符合受众理解。 解释说明单位和“其他条件不变”的限定，而不只是展示系数的正负和数值。

如果条件不成立，更准确的说法是：“模型具有简单的线性形式，但不能可靠地把各个系数当作独立解释。”

9. 总结与下一课

线性模型便于直接检查，因为它公开了明确的预测公式。但有意义的解释远不止读取系数的正负号。

  • 公式展示特征与参数如何组合成预测。
  • 在其他特征保持不变且编码明确时，系数描述特征每变化一个单位带来的预测变化。
  • 局部贡献取决于特征值与参考点。
  • 尺度决定系数数值以及比较是否有意义。
  • 特征相关、系数不稳定、模型设定错误、外推，以及把相关误当因果，都会破坏简单化的解释。

01线性模型Linear model

预测值由特征与参数的线性组合表示。

02系数Coefficient

其他特征不变时，描述特征每变化一个单位所引起的预测变化。

03截距Intercept

所有特征为零时公式给出的数值；含义取决于参考点。

04局部贡献Local contribution

某个特征相对选定参考值的偏差所对应的预测组成部分。

05中心化Centering

减去特征参考值，使解释更直观。

06标准化Standardization

利用均值和标准差把特征变换到共同尺度。

07多重共线性Multicollinearity

特征之间较强的依赖关系，可能使单个系数不稳定。

08外推Extrapolation

在未验证模型适用性的观测数据范围之外使用模型。
