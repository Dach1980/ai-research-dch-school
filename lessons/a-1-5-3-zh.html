核心问题混淆矩阵展示了模型产生四种结果的次数。怎样把这些数量转化为有意义的指标？为什么“93% 的预测正确”仍然不能说明系统发现危险事件的能力有多强？

1. 从混淆矩阵到评价指标

在 1.5.2 课中，我们已经学会读取二分类混淆矩阵。本课将使用矩阵中的数量计算评价指标。先回顾符号：TP 表示正确发现的正类；TN 表示正确识别的负类；FP 表示误报；FN 表示漏掉的正类。

分类评价指标是根据带标签的评估数据计算出的数值，用来描述模型行为的某一个方面。它不是通用的“智能分数”：指标的含义取决于分子和分母分别包含哪些样本。

关键概念——评价指标：根据模型预测结果与真实标签计算的、具有明确数学定义的数值。它回答分类器行为中的一个具体问题，但不能代替对任务本身及错误代价的分析。

本课讨论只有一个指定正类的二分类任务。四项指标都来自同一个混淆矩阵。如果改变模型把分数或概率转换为类别时使用的判定阈值，TP、TN、FP 和 FN 就会改变，指标也可能随之变化。关于不同阈值下的行为，我们将在 1.5.4 课中继续学习。

2. Accuracy——全部预测中的正确比例

Accuracy（准确率）回答：在所有被评估的对象中，无论属于正类还是负类，有多少比例得到了正确预测？

Accuracy：正确分类数量（TP 与 TN）占全部评估对象数量的比例。
Accuracy 公式Accuracy = (TP + TN) / (TP + TN + FP + FN)

符号说明：TP 和 TN 是正确的正类与负类预测；FP 和 FN 是两种错误。分母是整个评估数据集。简单来说，把所有正确预测相加，再除以检查过的对象总数。

在 1.5.2 课的例子中，TP = 18、TN = 168、FP = 12、FN = 2。正确预测为 18 + 168 = 186 个，共评估 200 个对象。因此 Accuracy = 186 / 200 = 0.93，即 93%。

当类别数量以及不同错误的代价大致相当时，Accuracy 可以作为总体参考。但它也可能掩盖严重问题。如果正类很少，一个始终预测“负类”的模型也可能获得很高的 Accuracy，却一个需要发现的正类都找不到。因此必须结合类别构成和其他指标一起解读。1.5.5 课将更深入讨论少数类与类别不平衡问题。

3. Precision——正类预测有多可靠

Precision（精确率）回答：当模型把一个对象预测为正类时，这个预测有多大概率是正确的？它只考虑模型预测为正类的对象。

Precision：模型所有正类预测中，真正属于正类的比例。
Precision 公式Precision = TP / (TP + FP)

符号说明：TP 是正确的正类预测；FP 是错误的正类预测。TP + FP 表示模型发出的全部正类信号。在正确发现数量不变时，误报越多，Precision 就越低。

在本例中，模型发出了 30 次正类警报：其中 18 次正确，12 次误报。Precision = 18 / (18 + 12) = 18 / 30 = 0.60，即 60%。换句话说，每十次警报中平均有六次得到确认，另外四次属于误报。

如果每次正类判断都会触发昂贵或耗时的人工检查，例如专家必须逐一检查每条警报，那么 Precision 就非常重要。较高的 Precision 能减少无效警报的比例。但它不能告诉我们模型漏掉了多少真实正类；这正是 Recall 要回答的问题。

4. Recall——真实正类中有多少被发现

Recall（召回率，也称灵敏度）回答另一个问题：在所有真实属于正类的对象中，模型发现了多少比例？

Recall：真正例占全部真实正类对象的比例。它也称为灵敏度（sensitivity）或真正例率（True Positive Rate，TPR）。
Recall 公式Recall = TP / (TP + FN)

符号说明：TP 是模型发现的真实正类；FN 是模型漏掉的真实正类。TP + FN 是所有真实正类对象的数量。漏报 FN 越多，Recall 就越低。

在例子中，实际有 20 个带裂纹的零件：系统发现了 18 个，漏掉了 2 个。Recall = 18 / (18 + 2) = 18 / 20 = 0.90，即 90%。这意味着系统发现了十个真实缺陷中的九个。

当漏掉危险事件的代价特别高时，Recall 尤其重要，例如筛查、故障检测或威胁发现。但 Recall 高并不意味着正类警报一定准确。模型可能几乎发现所有真实案例，却同时产生大量误报，导致 Precision 较低。

核心区别：Precision 从模型预测为正类的对象开始计算；Recall 从真实正类对象开始计算。两者分母不同，不能互相替代。

5. F1——综合考察 Precision 与 Recall

有时我们既关心正类预测是否可靠，也关心模型能否找到真实正类。Precision 与 Recall 的普通算术平均可能会在一个指标很高、另一个很低时显得过于乐观。F1 提供了另一种平衡方式。

F1-score：Precision 与 Recall 的调和平均数。只有两项指标都足够高时，F1 才会较高；其中任意一项较低，都会明显拉低 F1。
使用 Precision 和 Recall 表示的 F1 公式F1 = 2 × (Precision × Recall) / (Precision + Recall)

这里 Precision 和 Recall 的取值范围为 0 到 1。系数 2 用于规范调和平均，使两个指标都为 1 时，F1 也等于 1。还可以直接用混淆矩阵中的数量表示：

F1 的等价公式F1 = 2TP / (2TP + FP + FN)

还需要注意计算边界：如果模型没有给出任何正类预测，TP + FP = 0，Precision 就无法通过普通除法计算；如果评估数据中没有真实正类，TP + FN = 0，Recall 也没有定义。软件库可能发出警告、返回 0 或使用其他预先配置的值。报告中应说明采用的处理规则，不能把这种特殊值当作普通测量结果。

在本例中，Precision = 0.60，Recall = 0.90。因此 F1 = 2 × 0.60 × 0.90 / (0.60 + 0.90) = 1.08 / 1.50 = 0.72，即 72%。F1 低于 Recall，是因为 Precision 明显较弱。这不是计算错误，而是说明正类预测的两个方面并不平衡。

F1 不会直接计入 TN，也不表示错误在金钱、时间或风险方面的真实代价。它并不是任何场景下都最好的指标。如果漏掉事件比误报更严重，Recall 可能更重要；如果误报代价过高，Precision 可能更重要。只有在需要用一个数值综合表示这两方面、并且认为两者同等重要时，F1 才特别有用。

6. 比较模型，并根据任务选择指标

回到 200 个零件的检测任务：其中 20 个有裂纹，180 个没有裂纹。我们在同一评估数据集上比较两个模型。模型 A 就是前面的例子。模型 B 发现了 16 个缺陷，漏掉 4 个，产生 4 次误报，并正确识别了 176 个完好零件。

F172%80%

模型 B 的 Accuracy、Precision 和 F1 更高，但 Recall 更低：它漏掉了 4 个缺陷，而不是 2 个。如果首要目标是不漏掉危险缺陷，那么尽管模型 A 的误报更多，它仍可能更合适。如果人工复核能力有限，而且漏掉一个缺陷的代价相对较低，模型 B 可能更实用。选择取决于应用场景，而不是哪一个模型在更多表格列中获胜。

本例中的所有指标都基于同一条固定规则：将模型分数转换为正类或负类。改变判定阈值会改变 FP 与 FN 的比例，进而改变 Precision、Recall 和 F1。下一课将使用 ROC 与 Precision-Recall 曲线，研究模型在多个阈值下的表现。

实践原则：先确定必须避免哪一种错误，再选择对该错误敏感的指标，最后检查其他指标以及实际流程中的限制。

7. 实践练习：计算四项指标

某分拣系统又检查了一批 200 件产品。独立复核得到 TP = 42、FP = 8、FN = 18、TN = 132。请先独立计算 Accuracy、Precision、Recall 和 F1。先写出未四舍五入的分数，再转换为百分比。

  • 模型正确分类了多少件产品？
  • 模型发出了多少个正类警报，其中多少比例是正确的？
  • 实际缺陷中有多少被发现？
  • F1 是多少？为什么它低于 Precision？
解题过程

对象总数：42 + 8 + 18 + 132 = 200。正确预测：42 + 132 = 174。因此 Accuracy = 174 / 200 = 87%。

正类预测：42 + 8 = 50。Precision = 42 / 50 = 84%。

真实正类对象：42 + 18 = 60。Recall = 42 / 60 = 70%。

F1 = 2 × 0.84 × 0.70 / (0.84 + 0.70) = 1.176 / 1.54 ≈ 76.4%。由于 Recall 明显低于 Precision，F1 也低于 Precision。四个数描述的是同一个混淆矩阵，却回答不同的问题。

总结与下一步

Accuracy 表示全部预测中的正确比例；Precision 表示正类警报的可靠程度；Recall 表示模型发现真实正类的比例；F1 使用调和平均综合 Precision 与 Recall，但不包括 TN，也不能代替对错误代价的分析。

没有任何一个指标能够自动选出最佳模型。首先定义正类以及 FP、FN 的后果，然后读取混淆矩阵，计算多个指标并解释其中的取舍。在 1.5.4 课中，我们将从一个固定阈值下的结果，进一步学习 ROC-AUC 与 Precision-Recall AUC，研究模型在阈值变化时的表现。
