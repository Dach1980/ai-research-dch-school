1.5.7 — 回归指标：MAE、MSE、RMSE 与 R²

学习目标

完成本课后，你将能够：

  • 根据预测类型区分回归与分类。
  • 计算 MAE、MSE 和 RMSE。
  • 解释大误差的影响和计量单位。
  • 解释 R²，包括负值。
  • 在相同数据上将模型与基线比较。
  • 结合尺度和错误代价选择指标。
核心问题需求预测可能偏差 2 个单位，也可能偏差 200 个单位。单一平均值无法说明罕见的大误差是否危险。

1. 回归任务与残差

回归预测数值，例如价格、时间、温度、需求或能耗。第 i 个样本的实际值为 yᵢ，预测值为 ŷᵢ。残差 eᵢ = yᵢ − ŷᵢ。正残差表示预测偏低，负残差表示预测偏高。

若实际需求为 120，预测为 110，残差为 +10。若实际值为 80，预测为 90，残差为 −10。方向不同，但绝对误差都是 10。指标汇总样本误差，不能替代分组和场景分析。

2. MAE：平均绝对误差

MAE 是预测误差绝对值的平均数。误差 20 对总和的贡献是误差 10 的两倍。它使用目标变量的原始单位：MAE = 6 分钟表示平均绝对偏差为六分钟。

MAE 不显示偏差方向：系统性低估和高估可能得到相同分数。与平方误差指标相比，它对单个大误差不那么敏感，但仍会受到离群值影响。

MAE
MAE = (1/n) Σ |yᵢ − ŷᵢ|
n 是样本数；yᵢ 是实际值；ŷᵢ 是预测值。对残差绝对值求平均。

3. MSE：均方误差

MSE 是残差平方的平均值。平方会不成比例地放大大误差：20² = 400，而 10² = 100。当罕见的大偏差代价很高时，这一指标很有用。

缺点是单位变成平方单位。如果目标单位为 kWh，MSE 的单位为 (kWh)²。平方损失也对离群值和标注错误敏感，得出结论前应检查极端值。

MSE
MSE = (1/n) Σ (yᵢ − ŷᵢ)²
对残差平方后求平均，单位变为目标单位的平方。

4. RMSE：均方根误差

RMSE 是 MSE 的平方根。它保留大误差权重更高的特点，同时将结果恢复为目标变量的原始单位。因此，温度预测的 RMSE 可以用摄氏度讨论。

RMSE 不等于 MAE：它采用不同的汇总方式，对大残差反应更强。如果 RMSE 明显高于 MAE，可能存在少数大误差。应检查残差，而不是直接假定原因。

RMSE
RMSE = √MSE
对 MSE 开平方，恢复目标变量的原始单位。

5. R²：决定系数

标准定义为 R² = 1 − SSE/SST，其中 SSE = Σ(yᵢ − ŷᵢ)²，SST = Σ(yᵢ − ȳ)²；ȳ 是实际值的均值。

R² = 1 表示预测完全准确。R² = 0 表示按平方误差衡量，模型不优于预测评估集均值。负值表示模型比该基线更差。R² 不是预测正确率百分比，也不能证明因果关系。

R² 取决于样本组成和目标变量方差。报告评估数据，并结合 MAE 或 RMSE。

R²
R² = 1 − SSE / SST
SSE 是残差平方和；SST 是实际值相对均值 ȳ 的离差平方和。

6. 同一组误差，不同结论

假设绝对误差为 A = [2, 2, 2, 10]，B = [4, 4, 4, 4]。两者 MAE 都是 4。但 MSE(A) = 28，MSE(B) = 16；RMSE(A) ≈ 5.29，RMSE(B) = 4。如果大误差代价很高，B 更合适。

没有脱离背景的万能指标。MAE 表示平均绝对误差，RMSE 强调大误差，R² 将平方误差与均值基线比较。还应检查残差。

关键结论MAE 表示平均绝对误差；RMSE 对大误差更敏感。

7. 与基线比较并进行诚实评估

复杂模型应优于简单策略。连续目标的基线可以始终预测训练集均值；时间序列可以使用最近值或季节值。基线应符合真实场景，不能利用测试答案设计。

模型和基线只能在训练数据上拟合。MAE、RMSE 和 R² 应在相同验证集或测试样本上比较。若使用 1.5.6 的交叉验证，应在相同折上比较模型，并将最终测试集留到最后。

不同目标单位或尺度下，绝对误差指标不能直接比较。还应按目标范围、地区和时间段检查误差。

8. 局限与常见错误

不要把 MAE 和 RMSE 当成相同指标：MAE 线性汇总绝对误差，RMSE 提高大误差的权重。不要把 MSE 写成目标变量的原始单位。不要把 R² 理解为准确率百分比。

目标值为零或接近零、分布偏斜、错误代价不对称以及离群值，都可能要求补充指标和分组分析。先明确哪种错误代价高、哪些单位有意义，再选择指标、基线和独立评估。

实践练习

实际值：[10, 12, 15, 20, 25]。预测值：[12, 11, 14, 18, 35]。计算残差、MAE、MSE、RMSE 和 R²。将最后一个预测 35 改为 27 后重新计算。解释哪项指标变化更大以及原因。与始终预测训练集均值的基线比较。注明单位，不要把 R² 称为准确率百分比。

提交结果残差表、四项指标、基线比较和简短解释。

总结与下一步

回归评估不是寻找一个万能数字。应结合单位、离群值敏感性、基线和实际错误代价解释模型表现。下一主题将学习可复现实验所需的工具与数学基础。
