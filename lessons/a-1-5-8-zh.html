1.5.8 — 概率校准与概率预测质量

模型可能擅长对样本排序，却给出不可靠的概率。学习如何评估概率预测，并以正确方式进行校准。

学习目标

完成本课后，你将能够：

  • 区分样本排序与概率校准。
  • 解释可靠性图和校准曲线。
  • 计算 Brier score 并理解 log loss。
  • 识别过度自信与信心不足。
  • 根据数据量选择 Platt scaling 或 isotonic regression。
  • 建立避免数据泄漏的校准流程。
核心问题如果模型给一千个样本都分配 0.8 的概率，事件是否会在其中约 800 个样本中发生？仅凭较高的 ROC-AUC 无法保证这一点。

1. 概率不等于类别标签

在分类任务中，模型通常先输出 score 或概率，再由阈值转换为类别标签。如果预测为 0.73，阈值为 0.5，样本就被标记为正类。但标签并不能说明 0.73 这个概率是否可靠。两个模型可能以相同顺序排列样本，并取得相近的 ROC-AUC，却分别输出 0.2 / 0.8 和 0.45 / 0.95。排序能力可能相近，概率数值却有明显差异。

概率校准回答的是：预测概率是否符合事件的实际发生频率？对于理想校准的模型，在被预测为 0.8 的可比样本中，事件应约有 80% 发生。这一说法针对足够大的可比样本组，而不是单个样本；单个事件的结果仍具有不确定性。

需要区分三个属性。Discrimination 或 ranking 表示模型能否将真实正例排在负例之前；Calibration 表示概率数值是否符合频率；Sharpness 表示预测是否远离基准频率、更多集中在 0 或 1 附近。只有校准良好的尖锐预测才有价值。

例如，设备故障风险系统给出 0.9。这并不意味着某一台设备必然故障。但如果数百台风险预测约为 0.9 的相似设备中，只有一半发生故障，说明模型系统性地高估了概率。

概率校准概率模型的一种性质：被赋予相同预测概率的样本中，事件实际发生的比例与该预测概率相符。

2. 如何阅读校准曲线

可以使用可靠性图（reliability diagram）检查校准。先将预测分成若干区间（bins），再分别计算每个区间的平均预测概率和正例实际比例。横轴表示平均预测概率，纵轴表示观察到的事件频率。

对角线 y = x 表示理想校准。点 (0.8, 0.8) 表示平均预测概率为 0.8 的样本组中，事件实际发生率为 80%。点位于对角线下方表示过度自信（overconfidence）：预测概率高于实际频率。点位于对角线上方表示信心不足（underconfidence）：实际频率高于预测。

期望校准误差（ECE）
ECE = Σᵦ (nᵦ / n) · |acc(b) − conf(b)|

按区间比较平均预测概率与实际频率。n_b 是区间 b 的样本数，acc(b) 是该区间事件实际比例，conf(b) 是平均预测概率。ECE 越低表示区间平均绝对偏差越小，但结果取决于分箱方式。

分箱方式会影响图形。bins 太少会掩盖细节；bins 太多则每个区间样本过少，频率容易波动。建议同时显示每个区间的样本数或预测概率直方图。等宽分箱和等样本数分箱适合回答不同的分析问题。

不要仅凭一张好看的图就判断校准质量。还要检查样本量、实际频率的不确定性，以及地区、客户类型、时间段、设备类别等重要子群。总体校准良好也可能掩盖小规模但重要群体中的严重偏差。

3. Brier score：概率预测误差

对于二元结果，若事件发生则将实际值 yᵢ 编码为 1，否则编码为 0。预测概率 pᵢ 位于 0 到 1 之间。Brier score 是概率与实际结果之差的平方的平均值。理想预测时它为 0，数值越小越好。

如果预测为 0.8 且事件发生，贡献值为 (0.8 − 1)² = 0.04。如果同样预测为 0.8 但事件没有发生，贡献值为 (0.8 − 0)² = 0.64。因此，信心十足却预测错误会受到更大惩罚。Brier score 是 proper scoring rule：从期望角度看，诚实报告真实概率可以使评分最优。

考虑四个预测：0.1、0.2、0.8、0.9；实际结果为 0、1、1、1。Brier score = (0.01 + 0.64 + 0.04 + 0.01) / 4 = 0.175。数值取决于事件发生率和数据集，因此应在相同样本与任务上比较模型。

Brier score 同时受到校准能力和区分能力影响，并非纯粹的校准指标。应结合可靠性图、事件基准发生率和排序指标进行诊断。

Brier score 公式
BS = (1/n) Σᵢ₌₁ⁿ (pᵢ − yᵢ)²

其中 n 为样本数，pᵢ 为预测概率，yᵢ 为实际结果（0 或 1）。对概率误差的平方求平均。

4. Log loss 与过度自信错误的代价

Log loss（对数损失，也称二元交叉熵）评估模型分配给实际发生结果的概率。如果 y = 1，相关概率是 p；如果 y = 0，则是 1 − p。真实结果获得的概率越低，惩罚越大。例如，模型以 0.99 的概率预测事件发生，但事件实际没有发生，就会受到很大惩罚。

与 Brier score 不同，当模型分配给真实结果的概率趋近于 0 时，log loss 没有固定上界，会持续增大。因此它对过度自信的错误尤其敏感。实际计算中可用很小的 epsilon 限制概率，以保证数值稳定，但不能借此掩盖糟糕的预测。

Brier score 和 log loss 都是 proper scoring rules：正确计算时，真实概率在期望意义下使评分最优。但它们的数值仍受事件发生率、类别区分能力和评估样本影响。不能用不同测试集上的数字直接宣布某个模型更好。

如果概率用于决策，例如准备储备资源、安排检查优先级或评估风险，那么概率数值本身的误差可能比排序更重要。应根据实际应用后果选择指标。

Log loss 公式
LL = −(1/n) Σᵢ [ yᵢ ln(pᵢ) + (1−yᵢ) ln(1−pᵢ) ]

pᵢ 为事件预测概率，yᵢ 为 0/1 实际结果，ln 为自然对数。公式使用实际发生结果对应的概率。

5. 校准方法：Platt scaling 与 isotonic regression

校准是在已训练分类器输出之上增加的变换。基础模型先产生 score 或概率，再由校准器将其转换为更可靠的概率。这并不能自动修复错误特征、数据分布变化或较差的排序能力。

Platt scaling 对原始 score 拟合逻辑变换。它结构紧凑，在校准样本较少时通常更稳定，但假设 score 与概率之间的关系相对简单。二分类时可写为 sigmoid(a·s + b)，其中 s 是原始 score，a 和 b 使用独立校准数据拟合。

Isotonic regression 拟合单调、分段常数的变换。它更灵活，可以修正非线性失真，但需要更多数据。在样本较少时，它可能拟合噪声，导致新样本上的表现变差。应在独立数据上比较方法，而不是只看训练后的曲线是否漂亮。

现代神经网络还常用 temperature scaling：在 softmax 之前，将 logits 除以正温度 T。它会改变概率分布的置信程度，通常保留类别排序。该方法常用于多分类校准，但不能保证修复所有类型的误差。

Platt scaling 变换
p̂ = 1 / (1 + e⁻⁽ᵃˢ⁺ᵇ⁾)

s 是模型原始 score；a 和 b 是在独立校准集上拟合的逻辑变换参数。

6. 避免数据泄漏：在哪里拟合校准器

最大的风险是数据泄漏。如果校准器使用与基础模型相同的训练样本拟合，预测就会过于乐观，因为基础模型已经见过这些样本的标签。也不能使用最终 test 集来选择校准方法或参数。

一个简单且安全的流程是将数据分为 train、validation/calibration 和 test。只用 train 训练基础模型。对模型没有用于拟合的 calibration 样本生成预测，再用这些预测及其真实标签拟合校准器。固定整个流程后，最后只在 test 上评估一次。

数据较少时，可使用 out-of-fold predictions：每个样本都由未使用该样本训练的基础模型进行预测，并保存这些预测。随后用它们训练校准器。所有预处理、特征选择和重采样都必须留在训练折内部。1.5.6 课中介绍的嵌套评估原则有助于避免整个调参流程产生乐观偏差。

部署后，应持续监控不同时间和子群中的校准情况。事件发生率、用户行为或数据采集方式变化，都可能破坏概率与现实之间的对应关系。重新校准需要新的已标注数据，并再次进行独立评估。

7. 局限与常见错误

样本量较小时，各 bins 中的实际频率不稳定。校准曲线不是精确规律；应显示样本数，并在数据允许时给出不确定性区间或 bootstrap 估计。

一条总体曲线可能掩盖 subgroup miscalibration：模型可能在一个群体中高估风险，在另一个群体中低估风险。应分析与应用和公平性有关的群体，但不要把数据切分得过细，以免每组事件数量过少。

校准不会自动提高 ROC-AUC，也不能保证决策阈值更优。单调变换通常保留排序，却改变概率数值的解释。决策阈值仍应根据错误代价和业务约束单独选择。

常见错误包括：把 0.8 当成对单个事件的承诺；在校准器自身训练数据上评估；用 test 选择方法；比较不同样本上的 Brier score；忽略基准发生率；根据样本过少的 bins 下结论；数据漂移后不再检查。

8. 总结：概率必须能够被检验

概率校准补充了排序指标。ROC-AUC 关注模型对样本的排序能力；校准曲线检查预测概率是否符合实际频率；Brier score 和 log loss 则用不同的惩罚方式评估概率预测。

方法选择取决于样本量和失真形态：Platt scaling 结构紧凑；isotonic regression 更灵活但更需要数据；temperature scaling 常用于神经网络 logits。任何校准器都必须使用未参与基础模型训练的数据拟合，最终 test 在最终评估前保持独立。

下一步是将校准后的概率用于真实决策：根据错误成本、资源限制和风险要求选择阈值。概率的价值不在于看起来可信，而在于它已在合适的数据上得到可靠性检验。

实践练习

八个样本的预测概率为 0.1、0.2、0.2、0.3、0.7、0.8、0.8、0.9。实际结果为 0、0、1、0、1、1、0、1。

将预测分为两组：低于 0.5 和不低于 0.5。分别计算每组的平均预测概率和事件实际比例，然后计算全部八个样本的 Brier score。

核对结果低概率组：平均预测 0.2，实际频率 0.25。高概率组：平均预测 0.8，实际频率 0.75。Brier score = 0.195。两组都存在轻微偏差，但样本量太小，不能据此作出确定结论。

总结与下一步

  • ROC-AUC 描述排序能力；校准描述概率与实际频率的一致性。
  • Brier score 和 log loss 用于评估概率预测，但不能替代可靠性图。
  • 校准器应基于独立预测或 out-of-fold 结果拟合；不能使用 test 集调参。
