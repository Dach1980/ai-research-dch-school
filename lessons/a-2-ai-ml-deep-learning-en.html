AI, Machine Learning and Deep Learning

Three terms often treated as synonyms describe different levels. Learn their relationship and classify systems by the mechanism they actually use.

Learning outcomes
  • Define the key concepts accurately
  • Distinguish methods and system components
  • Explain the main workflow using diagrams
  • Identify limitations and describe validation
Approx. 60 minutes

1. AI is the broad field

Artificial Intelligence includes rule-based systems, search, planning, symbolic reasoning, machine learning and combinations of these methods. The defining feature is the task and capability being engineered—not the presence of a neural network.

2. Machine Learning

Machine Learning (ML) uses data to estimate patterns or decision rules instead of relying only on manually written rules for every case. Training adjusts parameters to reduce an objective such as prediction error. The learned relationship is then applied to new inputs.

3. Deep Learning

Deep Learning (DL) is a part of machine learning based on neural networks with multiple layers of parameterized transformations. These layers learn representations from data. DL is influential in vision, speech and language, but often needs substantial data, computation and evaluation.

4. The nested relationship

Every deep-learning method is machine learning, and machine learning is part of AI. The reverse is not true: many AI systems do not learn from data, and many ML methods are not deep neural networks. Think of nested sets, not interchangeable labels.

5. Compare mechanisms

A rule-based filter applies explicit conditions. A decision tree learns feature tests from examples. A neural network learns numerical weights across layers. These systems may solve similar tasks, but their training needs, transparency and failure modes differ.

6. Classification examples

A chess engine using search and hand-designed evaluation may be AI without ML. A spam filter trained on labelled messages is ML. A transformer language model is DL, and therefore also ML and AI.

7. Review

Draw nested circles for AI, ML and DL. Place a rule-based expert system, a random forest and a transformer language model in the correct regions. Explain why not all AI is deep learning.

Review

Define the key terms in your own words, give a real-world example and explain how you would validate the system's output.

Key terminology

AI
The broad field of intelligent systems, including learning and non-learning methods.
Machine Learning (ML)
Methods that estimate patterns or decision functions from data.
Deep Learning (DL)
ML based on neural networks with multiple parameterized layers.
Representation
A numerical or structured form in which a system encodes useful information about an input.

Learning paradigms within ML

Supervised learning uses labelled examples. Unsupervised learning searches for structure without target labels. Reinforcement learning trains an agent through interaction and reward signals. These are learning settings, not synonyms for particular model architectures: neural networks can be used in more than one setting.

Feature engineering and representation learning

In classical workflows, people often design features from domain knowledge—for example, rolling averages or calendar indicators. Deep learning can learn internal representations from raw or lightly processed inputs. Learned representations can reduce manual feature design, but they do not remove the need for sound data, evaluation and domain understanding.

Choosing an approach

Model choice depends on available data, the target task, explainability needs, deployment hardware, latency, maintenance and the cost of mistakes. A simple rule or linear model may be preferable when transparency and reliability matter more than a small gain in benchmark score.
