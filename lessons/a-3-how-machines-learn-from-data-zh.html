机器如何从数据中学习

理解观测、特征、目标变量、损失函数、优化与泛化，以及为什么记住样本不等于学会规律。

学习目标
  • 准确解释本课核心概念
  • 区分相关方法与系统组件
  • 用图示描述主要流程
  • 识别局限并说明验证方法

1. 数据集的结构

数据集由观测（行）和特征（列）组成。监督学习中，每条样本还包含目标值，即模型需要预测的数值或类别。建筑能耗预测的特征可以包括室外温度、人员数量和时段，目标可以是每日能耗。

2. 特征与目标

特征是在预测时可用的信息；目标变量是希望估计的量。使用未来才会出现的信息会造成数据泄漏，使评估结果产生误导。

3. 算法与模型

学习算法寻找一组参数，使模型在训练样本上表现良好。模型是最终得到的参数化关系。损失函数衡量预测与目标之间的差异；优化器更新参数以降低损失。

4. 梯度下降

梯度下降沿着能够局部降低损失的方向调整参数。学习率控制每一步的大小。步长过大可能越过较优解，步长过小则使训练缓慢。现代优化器改进了这一迭代思想。

5. 学习范式

监督学习使用带目标标签的样本；无监督学习在没有目标标签的情况下寻找结构，例如聚类或低维表示；强化学习利用交互和奖励信号。

6. 泛化能力

有用模型应能处理来自目标环境的新样本。欠拟合意味着模型过于简单；过拟合意味着模型过度适应训练样本甚至噪声。验证集和测试集用于评估泛化。

7. 实践实验

用能耗数据拟合简单直线，比较训练误差与留出样本误差。每次只改变模型复杂度或学习率中的一个因素。不要把未来信息作为特征。

8. 理解检查

指出预测任务中的观测、特征和目标变量。解释为什么训练误差低并不保证模型能预测其他建筑，并举出数据泄漏例子。

案例：预测建筑能耗

一行数据可以代表一栋建筑的一天。预测前可用的特征包括室外温度、人员计划和星期几。目标是预测未来时段的能耗。预测时段结束后的电表读数不能作为特征，否则会把答案泄漏到输入中。应先划分数据，再拟合预处理步骤，并保留独立测试时间段。

从样本到优化目标

回归任务常用的损失函数是均方误差：计算每个预测值与目标值之差的平方，再求平均。平方会让较大的误差产生更大影响。损失函数是训练目标，并不一定等于业务场景中错误预测的真实代价。指标选择和模型评估将在A.5中详细讨论。

梯度下降的简单示例

对于直线模型 ŷ = w·x + b，训练过程调整w和b以降低损失。如果模型对许多样本的预测偏高，梯度会指出参数应朝哪个方向变化，以降低平均误差。学习率决定更新幅度。训练会重复进行，直到满足停止条件；这并不保证一定找到全局最优解。

为什么要划分数据？

训练集用于拟合参数和预处理步骤；验证集用于比较方案；测试集用于最终独立评估。时间序列应使用较早时期训练、较晚时期评估。对于同一建筑或设备的重复测量，可能需要按组划分，避免相关样本同时出现在不同数据子集中。

Python实践：训练与预测

import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[-10], [-5], [0], [5], [10], [15]])
y = np.array([2100, 1950, 1780, 1600, 1450, 1280])

model = LinearRegression()
model.fit(X, y)                    # 训练
prediction = model.predict([[7]])  # 推理
print(prediction[0])

X中的每一行代表一个观测，每一列代表一个特征。fit()根据样本估计模型参数；predict()将训练后的模型应用于新的温度输入。这只是流程示例，并不是经过验证的真实建筑能耗模型。

如何表示机器学习问题？

数据集由多个观测样本组成。每一行通常描述一个对象、事件或时间点，每一列表示一个变量。输入变量称为特征，通常记为X。在监督学习中，模型需要估计的值称为目标变量，通常记为y。以建筑能耗为例，室外温度、建筑面积和人员数量可以作为特征，每日实测能耗则是目标。特征必须在预测发生时已经可用；如果使用事件发生后才记录的变量，就会造成数据泄漏。

训练前应检查单位、缺失值、重复记录、异常值、时间戳以及目标值的测量方式。模型无法修复定义错误的目标，也无法自动纠正系统性错误的测量。数据质量和抽样过程本身就是学习问题的一部分，而不只是技术准备工作。

算法、模型、参数与损失函数

学习算法是利用训练样本构建或调整模型的过程。模型是将输入映射为输出的数学或计算对象。模型的参数是在训练中估计的数值，例如线性模型的系数或神经网络的权重。损失函数按照选定标准衡量预测与目标之间的差异。训练过程通过搜索参数来降低损失，有时还会加入正则化或其他约束。

损失函数并不等于现实世界中的价值。平方误差会更强烈地惩罚较大的数值误差；绝对误差对极端误差相对不敏感。分类任务常使用交叉熵训练概率预测。用于训练的损失与用于选择模型的评价指标可以不同，因此两者都需要说明理由。

用直观方式理解梯度下降

考虑简单模型ŷ = w·x + b，其中w和b决定直线的位置。训练时，算法先计算预测误差，再估计参数稍微变化时损失会如何改变，并沿着预期能够降低损失的方向更新参数。学习率控制每次更新的幅度。学习率过大可能越过最优区域，过小则会使训练非常缓慢。真实神经网络拥有大量参数，因此需要使用梯度和数值优化方法，而不是通过观察一条曲线来调整。

不同的学习方式

监督学习使用带有已知目标的样本。回归预测数值，分类预测类别或类别概率。无监督学习没有明确目标，任务可能是聚类、压缩或发现异常。自监督学习从输入数据自身构造训练信号，例如预测序列中被隐藏的部分。强化学习则利用与环境交互产生的奖励。不同学习方式回答不同问题，因此需要不同的评估设计。

泛化、欠拟合与过拟合

只有在新样本上也表现良好的模型才真正有用，而不只是记住训练样本。这种能力称为泛化。欠拟合表示模型过于简单或训练不足，无法捕捉重要规律。过拟合表示模型适应了训练数据中的偶然细节和噪声，因此训练分数很好，但在新数据上的表现较差。复杂度越高并不总是越好。应使用验证集和基线模型判断增加复杂度是否带来了可重复的改进。

正确划分数据并防止泄漏

训练集用于拟合参数和预处理步骤；验证集用于比较模型、特征和超参数；测试集保留到最后，提供独立评估。不要反复根据测试集分数调整模型，否则测试集会逐渐变成验证集。时间相关问题应保持时间顺序。如果多行数据属于同一建筑、患者或设备，应使用分组划分，避免相关样本同时出现在训练集和测试集中。

缺失值填补器、标准化器、编码器和特征选择器只能在训练折上拟合。将预处理与估计器放入同一个Pipeline，可以让交叉验证安全地重复整个流程。目标信息衍生的特征、未来信息、重复记录以及划分前执行预处理，也都可能造成数据泄漏。

案例：每日建筑能耗

假设数据集包含室外温度、建筑面积、人员数量和每日能耗。能耗是目标，前三项是候选特征。可以先用线性回归建立可解释的基线，并与常数预测基线进行比较。再按温度和人员数量检查残差。如果极寒天气下误差系统性增大，说明关系可能是非线性的，或者缺少重要变量。在独立测试数据上没有取得改进之前，不应断言复杂模型更好。

实践任务

设计一个小型预测研究。定义一行数据代表什么、目标变量是什么、至少三个特征是什么，以及每个特征何时可用。说明如何划分数据、选择基线、衡量误差和发现泄漏。再写出模型部署后可能失败的一个原因，例如季节变化、传感器更换或建筑运行方式改变。

补充实践：检查模型的学习过程

从预测误差到参数更新

在回归任务中，模型会为每个训练样本输出一个数值预测。损失函数将预测值与已知目标值之间的差异汇总为一个可优化的数值。均方误差会对较大的偏差给予更高惩罚，因为误差被平方；平均绝对误差的单位与目标变量相同，也较少受到少数极端误差的影响。选择哪种损失应结合任务和不同错误的实际后果。

在梯度下降过程中，算法估计每个参数变化时损失会如何改变，然后反复更新参数、重新计算预测并评估损失。训练曲线可以显示优化是否正在推进，但训练损失下降并不能证明模型具有泛化能力。还应监控验证集表现；如果继续训练损害了模型在新样本上的表现，就应停止训练或简化模型。

一次可靠实验应记录什么？

  • 目标变量的准确定义和单位；
  • 特征列表，以及每个特征何时能够获得；
  • 数据集版本和样本纳入/排除规则；
  • 数据划分策略，以及适用时使用的随机种子；
  • 基线模型、模型家族、损失函数和超参数；
  • 训练与验证指标，以及只在最后使用一次的测试结果；
  • 已知局限、缺失变量和部署后可能出现的变化。

这些记录使实验能够复现，也有助于区分真正的改进、偶然的数据划分结果和数据变化带来的影响。
