1. 模型、算法与数据

数据是学习样本；学习算法是寻找合适解的过程；训练后的模型是具有具体参数值的计算关系。三者相关，但不能混为一谈。

2. 架构与参数

架构描述计算结构及执行顺序；参数是训练过程中调整的内部数值。单特征线性模型为 ŷ = w·x + b：x是输入，w是权重，b是偏置。改变w或b会改变模型表示的直线。

3. 参数与超参数

参数从训练数据中学习，例如权重和偏置。超参数配置模型或训练过程，例如学习率、树深度和批量大小。它们通常在训练前或训练流程之外选择，并借助验证集比较。

4. 模型家族

线性模型计算特征的加权组合，通常较易检查；决策树依次判断特征并在叶节点预测；神经网络组合多个参数化变换层，可以表达复杂非线性规律，但通常需要更多数据和计算资源。

5. 训练与推理

训练阶段使用样本、损失函数和优化器估计参数；推理阶段使用固定的已训练模型处理新输入。普通推理不会更新权重。在线学习或微调是需要单独设计和控制的过程。

6. 需要保存什么？

可复现部署可能需要保存权重、架构配置、预处理步骤、类别映射、分词器、库版本和实验元数据。仅保存模型文件可能不够，输入必须按训练时相同方式转换。

7. 模型不等于完整产品

部署系统还包括输入验证、预处理、推理、后处理、业务规则、界面、监控和人工复核。即使模型数学上正确，单位不一致也会造成故障。

9. 实验与回顾

分别训练最大深度为1、2、3和5的决策树。保持训练集和验证集划分不变并比较误差。树更深通常会降低训练误差，但也可能拟合噪声，在新样本上表现更差。每次只改变一个超参数。

Python实践

import numpy as np
from sklearn.linear_model import LinearRegression
X = np.array([[-10], [-5], [0], [5], [10], [15]])
y = np.array([2100, 1950, 1780, 1600, 1450, 1280])
model = LinearRegression().fit(X, y)
print("weight:", model.coef_[0])
print("bias:", model.intercept_)
print("prediction:", model.predict([[7]])[0])

fit()估计参数，predict()对新输入执行推理。

术语表

架构（架构）
定义输入如何经过一系列运算转换为输出的结构。
参数（Parameter）
训练得到的内部数值，例如权重和偏置。
超参数（Hyperparameter）
控制模型结构或训练过程的配置选项。
训练（Training）
利用样本估计模型参数的过程。
推理（Inference）
使用已训练模型处理新输入，通常不更新参数。
预处理（预处理ing）
模型计算之前对输入数据执行的转换。

为什么必须保存完整流程？

假设训练数据使用一个已拟合的标准化器进行转换。部署时必须使用相同的标准化器和特征顺序。如果每次请求都重新计算均值和标准差，输入表示就会变化，预测可能不一致。应将预处理配置与模型一起保存，并测试完整流程，而不仅仅是模型对象。
