本课要解决的问题

如何理解模型为何给出某个预测？我们是否应该相信这种解释？

1. 为什么决策树看起来容易理解——何时确实如此

设想一个系统需要确定工业泵的检修优先级。它不只是输出“高风险”，而是依次提出问题：振动是否超过阈值？如果超过，温度是否也偏高？最后沿着路径到达包含决策的叶节点。与数百个神经网络参数相比，这条路径更容易追踪。

决策树通常被称为按设计可解释（interpretable by design）：模型自身的结构展示了预测逻辑。对于单个对象，我们可以列出导致结果的条件。但图示容易阅读，并不保证树训练良好、公平或稳定。

需要区分三个问题：规则是否可读？决策树捕捉数据规律的准确程度如何？在真实流程中使用该规则是否合理？这三个问题需要分别检查。深度为 25 层的树在形式上可以读取，实际却可能难以理解；较浅的树也可能很清晰，却在重要对象群体上出错。

本课范围。 我们讨论作为模型的决策树：结构、决策路径、划分标准和局限。任意黑箱的事后解释、因果分析与公平性审计属于其他主题。

2. 决策树由哪些部分组成

决策树由节点和连接节点的分支构成。根节点包含第一个测试条件。内部节点检查某个特征，并把对象送往其中一个分支。叶节点不再提出问题，而是输出类别或数值预测。

决策树（decision tree）依次检查特征条件，并在终端叶节点输出预测结果的模型。
根节点（root node）决策树的起始节点，包含对训练样本的第一次划分。
划分规则（split rule）根据某个特征进行测试，并将对象引导至其中一个子节点的规则。
叶节点（leaf node）不再包含后续测试、保存类别或数值预测的终端节点。

根节点（root node）：决策树的起点，包含对训练样本的第一次划分。

划分规则（split rule）：基于特征的测试，例如“振动是否大于 4.0 mm/s”。对于数值特征，算法选择阈值；对于类别特征，具体实现可能检查某一组类别。

分支（branch）：测试结果对应的路径，通常为真或假。二叉树的每次划分通常产生两个分支。

叶节点（leaf node）：终止节点，保存预测结果。分类树保存预测类别，通常还保存类别比例；回归树保存数值，通常是该叶节点中训练样本目标值的平均数。

3. 决策树如何作出判断：贯穿案例

假设任务是确定工业泵的检修优先级。使用两个特征：振动值（mm/s）和外壳温度（°C）。一个用于教学的树可能先检查振动是否大于 4.0。如果是，再检查温度是否大于 70。如果两个条件都成立，叶节点输出“优先检修”。如果振动不超过 4.0，树可能转而检查其他条件，例如紧急停机次数。

考虑一台振动为 5.2 mm/s、温度为 76 °C 的泵。第一步：5.2 > 4.0，条件成立，沿右侧分支前进。第二步：76 > 70，条件成立，再沿“是”分支前进。第三步：到达“优先检修”叶节点。这就是局部解释：列出对象从根节点到叶节点所经过的条件。

另一台泵的振动为 3.1 mm/s，则第一个条件不成立。如果该分支上没有检查温度，那么即使温度为 76 °C，也不会改变这条路径。这一点非常重要：模型只使用实际出现在该对象路径上的特征和条件。不能把一个未参与该路径的特征说成此次预测的依据。

下图只是教学示例，不构成工程或监管建议。4.0 和 70 这两个阈值仅用于说明机制，并非通用的安全界限。

4. 决策树如何选择划分

训练时，算法寻找一个条件，使样本被分到子节点后，目标值更加同质。分类任务可以使用基尼不纯度或熵来衡量同质性；回归任务通常使用均方误差或方差的下降量。

不纯度（impurity）衡量节点内目标类别混杂程度的指标；当所有样本都属于同一类别时，不纯度为零。

类别混合时，不纯度数值更高。

对于类别比例 pₖ，基尼指数等于 1 减去各类别比例平方之和。两个类别各占 0.5 时，基尼指数为 0.5；比例为 1 和 0 时，基尼指数为零。熵也用于衡量不确定性，纯节点的熵同样为零。

信息增益（information gain）：划分后不纯度的减少量。算法先计算父节点的不纯度，再减去各子节点不纯度的加权和。权重取决于进入每个子节点的样本数量。好的划分应有效区分类别，同时避免产生不合理的小群体。

假设有 8 条教学样本：4 条标记为“优先”，4 条标记为“常规”。父节点的基尼指数为 0.5。按振动划分后，左侧有 1 条优先、3 条常规；右侧有 3 条优先、1 条常规。两个子节点的基尼指数均为 0.375，因此加权基尼指数为 0.375，信息增益为 0.125。这只是小样本演算示例，并非真实训练结果。

算法会评估候选条件，并按所选标准选择较优划分。若多个条件的得分接近，可能得到不同的树。数据顺序、实现限制和随机性也会影响结果。

基尼不纯度G = 1 − Σ pₖ²G 表示节点不纯度；pₖ 表示第 k 类的比例；k 为类别数量。
熵H = −Σ pₖ log₂(pₖ)H 表示以比特为单位的不确定性；当 pₖ = 0 时，该项记为零。
信息增益IG = I(parent) − Σ (nⱼ / n) · I(childⱼ)I 为所选不纯度指标；nⱼ 为子节点样本数；n 为父节点样本数。
节点均方误差MSE = (1 / n) Σ (yᵢ − ȳ)²yᵢ 是第 i 个对象的目标值；ȳ 是节点内均值；n 是对象数量。
通往叶节点的路径x → test₁ → branch₁ → … → leaf每个 test 检查一个特征；branch 决定下一节点；leaf 保存预测结果。

5. 划分标准的公式究竟衡量什么

对于类别比例 p₁,…,pₖ，基尼指数可写为 1 − Σpₖ²。k 表示类别数，pₖ 表示节点中第 k 类的比例。可以把它理解为一个简化随机分类设想中的错误概率。

熵的公式为 −Σpₖ log₂(pₖ)。当 pₖ = 0 时，对应项按连续极限记为零。以 2 为底的对数用于衡量比特单位的不确定性。

划分后的加权不纯度，是每个子节点的不纯度乘以进入该节点的样本比例后再求和。信息增益等于父节点不纯度减去这一加权和。对于回归树，也可以使用均方误差，即节点中目标值与其均值之间平方偏差的平均值。

这些公式解释了选择原则，但并不意味着需要人工逐一测试所有阈值。树模型的实现会完成搜索。实际分析时，应了解所选标准、模型限制以及训练数据的来源。

6. 全局解释与局部解释

局部解释回答：为什么这个对象到达了这个叶节点？答案是从根节点到叶节点的完整条件路径、叶节点的预测结果，以及分类任务中支持该结果的类别比例或样本数量。

全局解释回答：整棵树总体上如何作出判断？需要检查完整结构、深度、叶节点数量、划分中使用的特征、样本在各叶节点中的分布，以及模型在独立数据上的表现。小树可以直接阅读图示；大树则可能需要规则摘要和统计表。

树的特征重要性通常汇总某个特征在所有相关节点中带来的不纯度下降。该指标依赖算法与数据，不等于因果效应，也不说明关系方向。相关特征之间的重要性可能被分摊；候选阈值或类别较多的特征有时会在划分搜索中占据优势。

局部路径与全局重要性回答不同问题。路径展示一个对象实际经历的测试；重要性汇总特征在整棵树中的作用。不要把两者混为一谈。

7. 为什么容易理解的树仍可能出错

过拟合（overfitting）决策树拟合了训练数据中的偶然模式（包括噪声），因而难以推广到新的观测对象。

树深度（tree depth）：从根节点到叶节点的最大边数。限制最大深度、节点继续划分所需的最小样本数，以及叶节点的最小样本数，有助于控制复杂度。

剪枝（pruning）删除对新数据表现帮助很小的分支，以控制决策树的复杂度。

预剪枝在训练过程中限制生长；后剪枝则先生成树，再根据复杂度与性能标准删除分支。

决策树对数据可能很敏感：训练样本稍有变化，就可能改变根节点划分及其下方的许多分支。特征高度相关时，算法可能在多个可替代特征中选择其中一个。如果阈值 4.0 附近的值具有相近表现，就不应把 4.0 当作自然界限。

其他风险还包括训练数据偏差、遗漏重要特征、目标泄漏、训练后环境变化，以及把叶节点中的类别比例过度解释为校准良好的概率。结构可解释性无法修复低质量数据，也不能证明决策公平。

8. 实践：追踪路径并审计稳定性

任务 A——局部路径。 对于振动为 5.2 mm/s、温度为 76 °C 的泵，写出每个测试条件、比较结果、选择的分支和最终叶节点。用一句话解释判断，但不要作因果推断。

任务 B——反例。 考虑振动为 3.9 mm/s、温度为 82 °C 的泵。如果第一个条件是振动 > 4.0，它会到达哪个节点？为什么高温可能不会影响这条路径？当振动变成 4.1 mm/s 时又会怎样？

任务 C——树模型审计。 检查：树有多深；每个叶节点有多少样本；训练集和测试集表现如何；重复训练时顶部划分是否稳定；特征是否相关；目标变量是否泄漏到输入；重要群体之间的表现是否相近？

优秀答案的标准： 完整追踪每个条件，解释阈值与叶节点的含义，报告叶节点规模与类别组成，并区分模型规则本身和模型局限。如果没有稳定性或群体数据，应明确说明缺失，不要自行补造。

9. 总结：解释是一条路径，而不是正确性的保证

决策树把部分预测逻辑显式呈现出来：节点检查特征，分支确定路线，叶节点输出结果。因此，我们可以通过一系列条件解释单个预测，也可以检查模型整体结构。

但易读不等于高质量。必须检查树深度、叶节点样本量、划分标准、留出数据表现、树的稳定性和潜在偏差。特征重要性不能证明因果关系，叶节点中的类别比例也不一定是校准良好的概率。

课程词汇表

01决策树Decision tree

依次检查条件，并在终端叶节点输出预测结果的模型。

02根节点Root node

包含第一次划分的树起始节点。

03划分规则Split rule

根据特征将样本分配到子节点的测试条件。

04内部节点Internal node

检查条件并选择分支的节点。

05叶节点Leaf node

保存类别预测或数值预测的终端节点。
