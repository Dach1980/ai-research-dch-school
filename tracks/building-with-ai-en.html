TRACK C · ENGINEERING

Building with AI

Build practical AI systems, from local language models and hardware configuration to Python APIs, RAG and MCP integrations.

Foundational to advanced engineering pathModules C0–C12Theory · Experiments · Projects

What you will learn

  • Estimate GPU, VRAM, RAM and context requirements.
  • Choose models and understand quantization formats.
  • Install and configure LM Studio.
  • Connect local models through Python APIs.
  • Build local RAG applications.
  • Develop MCP servers and integrate Web Search.
  • Validate performance, privacy and system security.

Curriculum

C0 · Introduction to local AILocal models, inference, privacy and licensing.
C1 · Hardware platformCPU, GPU, VRAM, RAM, CUDA and monitoring.
C2 · LLM architectures and formatsParameters, tokenizers, GGUF and quantization.
C3 · LM StudioInstallation, models, backend configuration and local server.
C4 · Generation controlPrompts, chat templates and generation parameters.
C5 · Local server and APIHTTP, REST, JSON and streaming.
C6 · Python for LLM applicationsIntegration, configuration, errors and tests.
C7 · MCP fundamentalsHost, client, server, tools and resources.
C8 · MCP with PythonServers, schemas, validation and testing.
C9 · MCP Web SearchSearch, sources and LLM integration.
C10 · Local RAGParsing, chunking, embeddings and retrieval.
C11 · Diagnostics and securityPerformance, threats and reproducibility.
C12 · Capstone projectA local AI application with documentation and tests.

Materials in development and prerequisites

The curriculum builds on material about local AI, LM Studio, Python and MCP Web Search. Before publication, each item will be reviewed for currency, completeness, code quality, lab work and publication rights.

Foundational Python is a prerequisite and may be covered through a separate linked learning path. AI-agent development is not part of the currently approved curriculum.
